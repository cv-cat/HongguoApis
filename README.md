# 📺HongguoApis

红果短剧数据与互动工具集（本地运行）。

## 简介

本项目提供红果短剧的搜索、剧集详情、播放地址解析、评论、弹幕等能力的本地实现，并附带一套可自行部署的 PC / TV 观看页面。

> ⚠️ 仅供个人学习与技术研究使用，严禁用于发布不良信息或违法内容。如有侵权请联系作者删除，后果自负。

## 功能一览

- 🔍 短剧搜索（关键词 + 翻页）
- 📺 剧集详情与播放地址（多清晰度直链）
- 💬 剧评 / 单集评论 / 回复 / 弹幕
- 🖥️ PC 网页版与 TV 大屏版前端（本地 HTTP 服务）

## 使用说明

本仓库仅保留项目介绍。完整功能代码在本地方案中维护，如需获取或交流，欢迎通过 [Issue](https://github.com/cv-cat/HongguoApis/issues) 联系作者。
